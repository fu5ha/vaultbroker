# vaultbroker

**WARNING**: Heavily AI-coded with little review of code, only high
level architecture. it is very specific to my needs. Dont use this.

Vaultbroker lets an AI agent use Bitwarden credentials without the broker
ever showing them to the agent. The agent asks for a use — fill this
login form in that browser session, or log in with this item's stored
passkey — and a person approves each use with a passkey. No secret value
reaches the agent's context, tool results, or logs.
